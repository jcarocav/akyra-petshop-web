# Carpeta del logo

Pon aquí el logo de Patitas:

- `logo.svg` (preferido) o `logo.png` con fondo transparente.

Se usa en el navbar y en el footer. El footer tiene fondo oscuro (marrón cálido), así que si el logo es de un solo color, que sea una versión clara para que se vea bien ahí. En el navbar el fondo es claro (crema), así que si tienes una versión oscura del logo, úsala ahí — o dime y dejamos dos versiones distintas en el código si hace falta.
